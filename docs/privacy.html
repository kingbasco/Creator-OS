Privacy policy

This policy describes Creator OS Automation, operated by Cyril Adesgha A. Contact: adesghacyril@gmail.com.

Purpose and access

Creator OS is a personal educational video production workflow. With the account owner’s authorization, the automation uses the Google Drive and Google Sheets APIs to read production plans, update episode statuses and links, and retrieve or store production assets and renders. The requested Drive and Sheets scopes can permit access beyond the Creator OS folders; project code is intended to confine routine operations to configured project files.

Data used and stored

The workflow uses episode topics, scripts, statuses, file identifiers, links, and media assets. Production records remain in the owner’s Google Drive and Sheets. Repository code and selected production material may be stored in GitHub, and job artifacts or temporary processing files may be stored by the execution environment.

Credentials

OAuth credentials and refresh tokens are configured as GitHub Actions secrets. They must not be committed to source code, placed on this website, or intentionally printed in logs. Access tokens are used to make authorized API requests.

Service providers and sharing

Google provides Drive and Sheets storage; GitHub provides repository storage and workflow execution. When narration is generated, the narration text is sent to Google’s Gemini API. Website hosting may be provided by GitHub Pages or Vercel, which may process ordinary request metadata under their own policies. Creator OS does not sell Google user data or use it for advertising. Google account data is not supplied to AI services to train general-purpose models.

Retention and deletion

Production files are retained until the owner deletes or archives them. GitHub artifacts follow their configured expiry. The owner can remove stored credentials, delete workflow artifacts and project files, or contact the operator for help. Removing authorization does not automatically delete previously created production files.

Control and revocation

The account owner can revoke Creator OS access through Google Account’s third-party connections settings at any time. Revocation stops future authorized requests once tokens are rejected. This website contains no login form, tracking scripts or advertising cookies.

Limited Use

Creator OS Automation’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
