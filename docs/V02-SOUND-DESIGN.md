# V02 Sound Design & Mastering

The V02 final mix uses only procedural, project-owned sound assets generated by `scripts/generate-v02-sfx.mjs`.

No stock library, subscription, or externally licensed sound pack is required.

## Sound language

- Ambient bed: very low-level harmonic texture, used to avoid dead silence without sounding musical.
- Transition whooshes: directional and tied to the seven authored scene handoffs.
- UI clicks / scan ticks: only where visible interface actions occur.
- Success / error cues: restrained feedback for test states.
- Human gate cue: separate approval tone to reinforce the review responsibility.
- Summary ticks: light punctuation across the final mental-model sequence.

Narration remains dominant at 0.93 composition volume. Effects are intentionally conservative and the final file is normalized after render.

## Master

The final render is native vertical 4K:

- 2160×3840
- 30fps
- H.264 video
- AAC 320kbps audio
- loudness target: -14 LUFS integrated
- true peak ceiling: -1.5 dBTP
- loudness range target: 11 LU

Commands:

- `npm run sound:v02`
- `npm run render:v02:final:4k`
- `npm run master:v02`
