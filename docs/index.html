How it works
01 / PLAN

A deliberate queue.

A Google Sheets calendar holds episode topics, production statuses and review links.

02 / PRODUCE

Build the episode.

The repository contains scripts, narration and motion graphics workflows. Google Drive stores production assets and finished renders.

03 / REVIEW

A human decision.

Finished episodes go through technical checks and human review before publishing.

Built for the creator, by the creator.

Google account access

When the owner authorizes the automation, it can read and update the production spreadsheet and access Drive assets and renders. The intended workflow is limited to the Creator OS project. The website itself does not request Google access.
