# V11 — Plan → Code → Test → Review: A Better Vibe-Coding Loop

78-second evergreen workflow explainer.

## Core visual
Use one circular workflow with live artifacts inside each stage:

1. Inspect — repo tree / current behavior
2. Plan — compact task plan
3. Code — focused diff
4. Test — checks running / passing
5. Review — diff + result + approval

The first pass should move deliberately so every artifact is readable. The second pass should run faster, showing the same loop as an iteration system rather than a one-time checklist.

## Strong transition
When a test fails, do not continue around the loop. The motion reverses one step to **Code**, the diff changes, then the test passes and the loop continues to **Review**.

## Message
The point is not a magic prompt. The point is keeping the agent inside a repeatable, reviewable workflow where failures stay close to the most recent change.

## Style
Continue the approved presenter-led Creator OS style. No top branding header. Keep each stage isolated with generous spacing. The loop line should stay behind cards and never cut through text.
