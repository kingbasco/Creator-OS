Target: 1080×1920, 30fps, 82 seconds before measured voice retiming.

## Motion thesis

V02 should explain the difference between next-line prediction and goal-driven execution through spatial continuity.

The system should feel authored and technical, not futuristic for its own sake.

### Scene rhythm

1. **Autocomplete vs agent** — begin tight on code, then pull back into a larger workspace.
2. **Goal** — task card becomes the anchor for repository search.
3. **Inspect** — focus travels across relevant files while context accumulates.
4. **Plan** — context resolves into a short ordered plan.
5. **Change** — files converge into a focused multi-file diff.
6. **Evaluate** — tests run, a failure appears, and the failure loops back into the next action.
7. **Review** — automated checks complete fast; the human approval gate arrives more slowly.
8. **Mental model** — steps compress into a single agent loop, then push forward to V03.

## Rules

- Visible change approximately every 0.8–1.5 seconds.
- Preserve source-to-destination continuity.
- Use critically damped physical motion for cards and camera-like moves.
- No floating decoration, random particles, neon AI glow, or robot metaphors.
- Code and terminal output must remain readable on mobile.
- Human approval should feel deliberately slower than automated execution.
- Use semantic Remotion elements so every object can animate independently.
