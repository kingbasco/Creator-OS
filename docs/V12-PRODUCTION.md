# V12 — Coding Tools Are Becoming Agents, Not Autocomplete

82-second month-end thesis video.

## Core contrast

**Autocomplete**
- one editor
- cursor / next-line suggestion
- human accepts or rejects
- no wider execution loop

**Agentic workflow**
- repository inspection
- file edits
- terminal / commands
- browser or connected tools
- tests
- iteration
- human review

## Opening motion
Begin extremely tight on a code editor cursor. One gray suggestion appears after the cursor. The user accepts it.

Then pull the camera back in stages:
1. full editor,
2. repository tree,
3. terminal,
4. browser/tool card,
5. test runner.

The single suggestion becomes one action inside a larger system.

## Role-shift sequence
Use large typography:

**Typing**
↓
**Directing**
↓
**Reviewing**

Under each state, show the associated artifacts:
- Typing: cursor + completion
- Directing: goal card + constraints + architecture
- Reviewing: diff + tests + permissions + approval

## Safety / accuracy
Agentic coding expands what software can do on the developer's behalf, so the episode should also show boundaries, permission controls, and human review. Avoid framing agents as eliminating developer responsibility.

## Style
Continue the approved presenter-led Creator OS direction. No top branding header. Clean editorial motion, generous spacing, working UI behavior, and no generic AI imagery.
