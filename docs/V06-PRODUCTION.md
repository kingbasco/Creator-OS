# V06 — Stop Giving AI One Giant Prompt

78-second explainer using the approved Creator OS presenter and motion language.

## Core visual
Start with a huge prompt card that expands until it overwhelms the screen. The prompt produces a tangled repo state: files moving in different directions, conflicting assumptions, and an unclear finish line. Then physically break the prompt apart into six structured cards:

1. Goal
2. Constraints
3. Inspect current state
4. Small task
5. Acceptance criteria
6. Test

The six cards should progressively assemble into one clean execution lane. Objects should transform rather than reset between scenes.

## Motion beats
- Giant prompt expands and becomes visually noisy.
- Hidden assumptions appear as small floating tags around it.
- The prompt splits into six cards with strong spacing and no overlap.
- Repo tree is inspected before edits begin.
- One small task card enters a focused code area.
- Acceptance criteria become a checklist.
- Tests run and flip from pending to passed.
- End on a clean loop diagram showing the repeatable workflow.

Keep all labels readable, maintain generous vertical spacing, and use the presenter only to direct attention. No top branding header.
