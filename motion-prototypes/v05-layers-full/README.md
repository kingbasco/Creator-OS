# V05 — Five Layers full visual draft

76-second silent visual draft for **The 5 Layers Behind Every AI-Built App**.

The approved V04 presenter and clean Creator OS motion language are reused, with the removed top branding labels kept out. The core story is one polished interface physically separating into five layers, then each layer becoming an explanatory working diagram.

Scene flow:
1. Interface pulls apart into five layers.
2. Interface responds to a login action.
3. Application logic turns the click into decisions.
4. Backend receives and coordinates the request.
5. Authentication, permissions and database resolve identity/data.
6. Infrastructure reveals deployment, configuration and logs.
7. One login travels through all five layers and returns a signed-in result.
8. Three bugs are mapped to the layer that owns them.

This draft is intentionally silent. No new TTS or paid AI generation is used before visual approval.
