# V06 — Giant Prompt opening prototype

18-second silent prototype for **Stop Giving AI One Giant Prompt**.

The first half shows one oversized prompt expanding until hidden assumptions surround it. The second half physically breaks the problem into six clearly spaced execution cards: Goal, Constraints, Inspect, Small Task, Criteria, and Test.

Spacing rules from V05 are retained: no labels overlap, no card covers another card's copy, and the presenter remains below the primary diagram.

No narration or paid generation is used in this prototype.
