# V07 — Full visual draft

80-second silent visual draft for **What Should AI Do — and What Should You Still Review?**

The episode uses a reversible → sensitive autonomy scale, then progressively increases human review as blast radius, access control, privilege and irreversibility rise. The centerpiece is a human approval gate that stops a destructive database change until its diff and impact are reviewed.

The visual tone is balanced: autonomy with guardrails, not fear of agents. Spacing rules from V05/V06 are retained so cards remain readable and never collide.

No narration or paid AI generation is used in this visual pass.
