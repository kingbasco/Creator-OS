# V05 — Five Layers opening prototype

18-second silent prototype for the opening of **The 5 Layers Behind Every AI-Built App**.

Direction:
- no top branding/header labels;
- reuse the approved original presenter from V04;
- one polished login UI becomes the first layer of a five-layer stack;
- the five layers physically fan apart rather than appearing as a static diagram;
- the interface is then isolated and shown behaving like a real UI.

No narration or paid generation is used in this prototype. The full 76-second episode should only move into TTS after the visual direction is approved.
